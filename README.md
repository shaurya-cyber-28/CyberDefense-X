# CyberDefense-X 🛡️⚡

> AI-Powered Cybersecurity Simulation & SOC Dashboard

CyberDefense-X is a modern cybersecurity simulation platform designed to replicate how a real-world SOC (Security Operations Center) monitors, detects, and visualizes cyber threats in real time.

Built with a futuristic cyberpunk-inspired UI, the project focuses on:

* 🌍 Real-time attack visualization
* 📊 Threat monitoring dashboards
* 🤖 AI-style threat detection
* 📜 Live security logs & alerts
* ⚡ Interactive analytics and animations

---

# 🚀 Features

* Real-time simulated cyber attack monitoring
* Global attack intelligence map
* Animated attack routes and live threat flow
* AI-style anomaly/threat detection system
* SOC dashboard with analytics and alerts
* Modern UI/UX
* Responsive and interactive frontend

---
